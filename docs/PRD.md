# Easy Music 产品需求文档

版本：v0.1（初稿）

日期：2026-10-15

状态：用于确定产品范围与指导首版开发

## 1. 产品定位

Easy Music 是一个基于网易云音乐账号与音乐资源的个人桌面音乐客户端。以听歌为核心，提供扫码登录、音乐搜索、推荐内容、个人歌单、播放队列及歌词展示，减少与听歌无关的干扰。

产品体验关键词：简洁、舒适、清晰、流畅。

首版默认面向 Windows 桌面，技术结构保留后续适配 macOS 的空间。项目名称暂定 Easy Music。

## 2. 产品目标

- 用户能够通过网易云音乐 App 扫码登录，并在下次启动时恢复有效登录状态。
- 用户能够快速找到音乐，访问自己的歌单，并稳定完成连续播放。
- 界面采用统一的浅色视觉风格，导航清晰，播放操作始终可达。
- 主题采用语义化设计变量，为后续深色模式预留完整切换能力。

## 3. 目标用户与核心场景

目标用户是已有网易云音乐账号、希望使用简洁桌面播放器的用户。

| 场景 | 用户期望 |
| --- | --- |
| 启动客户端 | 恢复播放队列与进度，由用户主动开始播放 |
| 日常听歌 | 快速打开喜欢的音乐、个人歌单和每日推荐 |
| 寻找音乐 | 搜索歌曲、歌手、专辑和歌单，进入详情并播放 |
| 沉浸听歌 | 查看封面、同步歌词，并便捷调整播放进度 |
| 整理音乐 | 喜欢或取消喜欢歌曲，收藏歌单，管理当前队列 |

## 4. 首版范围

P0 为首个可用版本必须完成的内容；P1 在核心播放链路稳定后补充。受上游接口与账号权限影响的能力，以联调验证结果为准。

| 模块 | P0：首版必须 | P1：后续完善 |
| --- | --- | --- |
| 账号 | 扫码登录、会话恢复、状态校验、退出登录 | 多账号切换 |
| 发现 | 推荐歌单、每日推荐歌曲（登录后） | 排行榜、私人 FM |
| 搜索 | 歌曲、歌单、专辑、歌手搜索；分页 | 搜索建议、热搜 |
| 我的音乐 | 我喜欢的音乐、创建和收藏的歌单 | 网易云音乐云盘 |
| 详情 | 歌单详情、专辑详情、歌手基础信息与热门歌曲 | 歌手完整专辑列表 |
| 播放器 | 播放控制、队列、播放模式、音量、基础音质选择 | 渐入渐出、更多音质 |
| 歌词 | 滚动歌词、当前行高亮、点击歌词跳转 | 逐字歌词、桌面歌词 |
| 收藏 | 喜欢/取消喜欢歌曲、收藏/取消收藏歌单 | 新建歌单、歌单内歌曲增删 |
| 本地体验 | 队列和进度恢复、最近播放、基础设置 | 本地音乐导入、下载管理 |
| 外观 | 完整浅色主题、深色主题变量预留 | 深色主题、跟随系统 |
| 桌面集成 | 最小化、最大化、关闭行为设置 | 托盘、全局快捷键、系统媒体控制 |

首版暂不包含视频/MV、直播、播客、社交动态、私信、评论互动、商城及会员购买；不承诺专业音频输出、无缝播放或全部特殊音频格式支持。

## 5. 信息架构与页面

整体采用「左侧导航 + 顶部工具栏 + 主内容区域 + 底部常驻播放器」布局。

### 5.1 左侧导航

- 发现音乐。
- 我的音乐：我喜欢的音乐、最近播放。
- 我的歌单：展示创建与收藏的歌单，支持滚动。
- 底部入口：用户头像/扫码登录、设置。

### 5.2 顶部工具栏

提供前进、后退和搜索入口。搜索框可输入关键词，按 Enter 进入搜索结果页。桌面窗口控制区与拖动区域划分明确。

### 5.3 发现音乐

以推荐歌单和每日推荐为主，采用留白充分的卡片布局。推荐内容加载失败时提供重试，不阻断导航和播放。未登录时，每日推荐区域提示登录；不展示与当前账号无关的伪个性化内容。

### 5.4 搜索结果

按歌曲、歌单、专辑、歌手切换结果类型。歌曲列表展示曲名、歌手、专辑、时长与喜欢状态；支持单曲播放和加入队列。关键词或结果类型变化时重置分页，避免旧请求覆盖新结果。

### 5.5 歌单与专辑详情

顶部展示封面、名称、作者/歌手、简介及歌曲数量，提供播放全部、加入队列和收藏入口。下方以列表展示歌曲。长简介默认收起；长列表按需加载或虚拟滚动。

### 5.6 歌手详情

展示头像、姓名、简介与热门歌曲，支持进入相关专辑。首版优先保证从搜索、歌曲列表进入歌手并继续找歌的路径完整。

### 5.7 我喜欢的音乐与我的歌单

读取当前账号的对应内容。喜欢和收藏操作成功后同步页面状态；失败时恢复原状态并提示原因。退出或切换账号时清理账号专属的界面数据与请求缓存。

### 5.8 最近播放

首版定义为本客户端的本地播放历史，不与网易云听歌排行混用。单曲成功进入播放状态后记录；重复播放时更新最近播放时间。支持清空记录。

### 5.9 播放详情

点击底部播放器中的封面或歌曲信息，进入大封面与歌词并列的播放详情视图。返回后恢复原页面位置，音乐保持播放。

## 6. 核心功能要求

### 6.1 扫码登录

唯一登录方式为二维码登录，不提供手机号、验证码或密码输入。

流程：打开登录面板 → 获取二维码 → 用户在网易云音乐 App 扫码 → 手机确认 → 客户端获取会话并加载个人内容。

必须覆盖以下状态：二维码加载中、等待扫码、已扫码待确认、登录成功、二维码过期、网络异常。

- 扫码相关请求携带时间戳，避免缓存导致二维码或状态不更新。
- 轮询仅在登录面板打开且二维码有效时进行；关闭面板、过期或登录成功后停止。
- 二维码过期后提供明确的刷新按钮；网络失败提供重试入口。
- 启动时优先校验已有会话，不自动反复发起登录。
- 登录失效时提示重新扫码；保留本地队列、设置和历史，个人内容停止刷新。
- 退出登录后清除本地会话与账号数据。当前已缓冲的音频允许自然停止，后续播放按未登录权限重新获取地址。
- Cookie 由桌面服务层安全保存，不写入普通日志，不向界面暴露完整凭证。

### 6.2 播放器

- 全局只有一个播放实例，页面切换、打开设置和进入歌词视图均不打断播放。
- 支持播放/暂停、上一首、下一首、进度拖动、音量调节和静音。
- 支持顺序播放、列表循环、单曲循环、随机播放；顺序播放在队列末尾停止。
- 单曲播放：歌曲已在队列时定位并播放；不存在时加入当前歌曲之后并播放。
- 播放全部：替换当前队列并播放所选列表第一首；空列表不触发播放。
- 加入队列：追加到队尾，同一歌曲 ID 默认不重复追加。
- 队列支持查看、选择播放、移除和清空。移除正在播放的歌曲时播放下一首；无下一首则停止。
- 切换歌曲时处理旧请求与旧音频事件，快速点击也不能出现歌曲信息和实际声音不一致。
- 默认选择标准音质，提供标准/较高/极高选项；请求音质不可用时允许回退，并显示实际播放音质。
- 无播放地址、试听、账号无权限、网络失败需分别给出可理解的提示。
- 自动播放遇到不可播放歌曲时跳过；同一轮中全部不可播放或发生连续网络错误时停止，避免无限重试。
- 播放地址按需获取，失效时重新请求；不把远程音频 URL 当作永久数据保存。

### 6.3 歌词

- 基于实际播放时间高亮当前歌词行，并平滑滚动。
- 用户手动滚动歌词后暂时停止自动跟随，提供回到当前行入口。
- 点击有时间戳的歌词可跳转；纯文本歌词仅展示。
- 无歌词、歌词加载失败、纯音乐均有对应占位状态。
- 首版优先支持逐行歌词，翻译歌词在接口返回时一并展示。

### 6.4 状态恢复与设置

- 保存音量、播放模式、队列、当前歌曲与播放进度；重新启动后恢复为暂停状态。
- 设置提供默认音质、关闭窗口时退出或最小化、清空最近播放与重置设置。
- 首版仅开放浅色主题；深色与跟随系统在完成适配后再开放，避免出现不可用选项。
- 用户退出登录不重置外观、音量及其他设备设置。

## 7. UI 与交互方向

### 7.1 浅色主题

- 整体使用暖白或中性浅灰背景，卡片和侧栏通过轻微色阶、细边框区分。
- 文字分为主要、次要、弱提示三个层级，避免大面积纯黑。
- 采用一个克制的品牌强调色，初步建议低饱和红色；用于主按钮、选中项和播放进度。
- 封面是主要视觉内容，减少大横幅、装饰性渐变和过重阴影。
- 统一圆角、间距、图标与字体层级；图标按钮应有悬停提示和明确点击反馈。
- 常见状态需有完整设计：加载、空内容、无搜索结果、失败、未登录、不可播放。

### 7.2 布局建议

建议初始窗口约 1280 × 800，最低适配 1024 × 680；在这些尺寸下主要播放控件均应完整可见。左栏约 220px，底部播放器约 80px，主内容区域自适应。

底部播放器分为歌曲信息、核心播放控制、音量及队列入口三组。列表行的次要操作在悬停或键盘聚焦时出现，保持默认界面清爽。

### 7.3 深色模式预留

颜色统一使用背景、表面、主文字、次文字、边框、强调色、悬停态等语义化变量，避免页面内散落固定色值。后续深色模式需要逐项校验封面边界、弹层、列表选中态、歌词和进度条。

### 7.4 基础可用性

- 核心按钮支持键盘聚焦，并展示可见的焦点样式。
- 输入框内按空格不触发播放快捷键。
- 支持 Windows 显示缩放，避免文字截断和窗口控件重叠。
- 动画保持轻量；歌词和长列表更新不应导致明显卡顿。

## 8. 技术方案约定

采用 Electron + Vue 3 + TypeScript + electron-vite + Pinia + Vue Router。

- 界面层负责展示和交互，播放器逻辑独立于页面组件。
- preload 暴露有限、明确的 IPC 方法，界面不直接访问 Node.js 或完整账号凭证。
- 音乐服务层封装上游 API、登录态、缓存与错误转换；优先通过独立 utility process 运行 API 包，具体兼容性在原型阶段验证。
- 首版采用 HTMLAudioElement 播放；优先验证常用音质的播放、拖动进度和连续切歌。
- 设置与队列采用轻量本地存储；当历史记录、缓存索引或本地音乐规模需要时再引入 SQLite。
- 上游 API 固定依赖版本，升级后验证扫码、搜索、个人歌单及播放链路。

## 9. 依赖与待验证项

- 本项目依赖第三方网易云 API 的可用性，部分能力可能随上游调整变化。
- 音质与完整播放权限以账号和接口实际返回为准，界面不得把请求音质直接标为实际音质。
- 原型阶段验证扫码 Cookie 持久化、重启恢复、会话失效行为，以及喜欢和收藏后的同步。
- 验证标准/极高音质下的播放、暂停、跳转、播放结束事件与异常恢复。
- 网络异常时保留可操作的本地界面；尚未实现音频离线缓存时，不承诺离线播放。

## 10. 交付阶段与验收

| 阶段 | 交付内容 | 验收重点 |
| --- | --- | --- |
| 阶段一：基础原型 | 桌面壳、浅色布局、扫码登录、搜索、单曲播放 | 真实账号登录并播放，退出重启后会话可恢复 |
| 阶段二：首版功能 | 推荐、个人歌单、详情、收藏、队列、歌词、设置 | 核心使用路径完整，切页与切歌稳定，失败状态可恢复 |
| 阶段三：体验完善 | 长列表性能、安装包、显示缩放、异常修复 | 安装后无需额外启动 API 服务，主要窗口尺寸下布局正常 |
| 阶段四：功能扩展 | 深色模式及按需选择的 P1 功能 | 每项功能独立验收，不影响已完成的播放链路 |

首版整体验收标准：

1. 用户可仅通过扫码完成登录，过期、取消及网络错误均有明确反馈。
2. 搜索歌曲、打开个人歌单、播放歌曲与播放全部均可完成。
3. 暂停、切歌、拖动进度、调整音量及切换播放模式行为符合预期。
4. 页面导航与歌词视图切换不打断播放；快速切歌不出现声音和信息错位。
5. 喜欢和收藏结果可在重新进入页面后正确反映。
6. 重启后恢复队列、音量与进度，保持暂停，不突然播放。
7. 不可播放、空列表、无歌词、登录失效和网络异常均不会使界面卡死或无限重试。
8. 浅色模式下导航、列表、详情、登录弹层、歌词与设置保持一致视觉风格。
